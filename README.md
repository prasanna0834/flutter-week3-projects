# Flutter Week 3 Project

This repository contains the **Clima Weather Application** developed during Week 3 of my Flutter Development Internship.

The project demonstrates how to fetch real-time weather information from a public API, process JSON responses, and display the data using asynchronous programming in Flutter.

## Project Included

### Clima Weather App

A Flutter weather application that retrieves weather information based on the user's current location or a searched city.

## Skills Practiced

- REST API Integration
- HTTP Requests
- JSON Parsing
- Asynchronous Programming
- Async/Await
- Error Handling
- Location Services
- State Management
